 ```text                                                                                                                                                             
default  当前主力模型
smol     快速便宜模型
slow     慢但更强的模型
vision   看图模型
plan     制定计划模型
commit   生成提交信息模型
tiny     极小型后台模型
memory   处理记忆模型
task     子任务模型
 ```                                                                                                                                                                 
                                                                                                                                                                     
 推荐的实际分配方式：                                                                                                                                                
                                                                                                                                                                     
 ```text                                                                                                                                                             
default:  日常编码能力均衡的模型
smol:     便宜快速模型
slow:     最强推理/代码模型
vision:   支持图片输入的模型
plan:     擅长分析和拆解任务的模型
commit:   smol 或 default
tiny:     本地小模型
memory:   tiny 或 smol
task:     default 或 slow
 ```
